# Cubefolks

Studio repo for the Cubefolks YouTube channel: creepy, curious first-person story Shorts in the blocky online-game style, built as
real 3D in code (Remotion + Three.js), voiced with Fish Audio, timed with Whisper, mixed and finished in Python.
Start with `CLAUDE.md`, then `notes/cubefolks/FIRST_TASKS.md`. Set up from the Beanfolk studio on 2026-11-13.
